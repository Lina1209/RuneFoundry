# RuneFoundry — Stage 3

Обновление основы мастерской: самостоятельные ячейки латиницы, кириллицы (включая Ё, Й, Ъ, Ь) и цифр; автосохранение в localStorage; строгая проверка JSON до импорта; нормализация SVG в квадрат 1000×1000 с масштабированием и центрированием; ZIP-экспорт проекта с JSON и SVG каждого нарисованного знака; обновление Service Worker с новой версией кэша.

## Важно
ZIP — это комплект проекта и изображений SVG, а не устанавливаемый шрифт. Генерация TTF/OTF/WOFF/WOFF2 пока не реализована и будет отдельным этапом.

## Установка
Распакуйте архив и загрузите содержимое в корень `Lina1209/RuneFoundry`, заменив одноимённые файлы. Сохраните папку `assets`.
