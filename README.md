# RuneFoundry

**RuneFoundry** — браузерная творческая лаборатория для создания авторских символов и рунических наборов.

## Состав проекта

- `index.html` — интерфейс мастерской.
- `styles.css` — оформление и адаптация под телефон/компьютер.
- `app.js` — логика рисования, таблицы символов, проектов и SVG-экспорта.
- `manifest.webmanifest` — метаданные для установки как PWA.
- `sw.js` — базовое кэширование приложения для повторного открытия.
- `assets/favicon.svg` — значок сайта.

## Публикация на GitHub Pages

1. Загрузите **содержимое этой папки** в корень репозитория `Lina1209/RuneFoundry`, а не саму папку `RuneFoundry_Web`.
2. Убедитесь, что `index.html`, `styles.css`, `app.js`, `manifest.webmanifest` и `sw.js` находятся рядом в корне репозитория.
3. В GitHub откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите Save.
6. После публикации сайт будет доступен по адресу `https://lina1209.github.io/RuneFoundry/`.

## Что работает в этой версии

- адаптивная оболочка сайта с разделами мастерской;
- рисование отдельных глифов пальцем, мышью или стилусом;
- таблица латиницы, кириллицы и цифр;
- отмена последнего штриха и очистка символа;
- сохранение/загрузка проекта JSON;
- экспорт текущего знака в SVG;
- базовая поддержка установки PWA и офлайн-кэша.

## Что пока не реализовано

Это ранняя версия интерфейса и редактора. Она **не генерирует устанавливаемые шрифты TTF/OTF/WOFF/WOFF2**. Предпросмотр сейчас показывает обычный текст, а не нарисованные глифы. Для полноценного генератора потребуются отдельные модули векторизации, метрик, кернинга, Unicode cmap и сборки шрифта.

## Внешние зависимости

Основная логика работает без серверной части. Google Fonts используется только для оформления; при отсутствии интернета применятся системные шрифты.
