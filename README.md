# RuneFoundry

Первая стартовая версия браузерной мастерской для создания рунических знаков.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере (Chrome, Firefox или Edge).
3. Выберите алфавит и символ, рисуйте знак пальцем или мышью.
4. Сохраните проект в JSON. Его можно будет загрузить обратно.
5. Экспорт SVG сохраняет рисунок выбранного знака.

## Что входит
- Поле рисования с поддержкой мыши и сенсорного экрана.
- Переключение латиницы, кириллицы и цифр.
- Несколько штрихов на один символ.
- Сохранение и загрузка проекта JSON.
- Экспорт выбранного знака в SVG.

## Важно
Это ранний прототип редактора рисунков символов, а не полноценный генератор шрифтов TTF/OTF. Для установки шрифта в Windows, Office и Google Docs потребуется следующий этап: нормализация контуров, метрики глифов, таблица Unicode и сборка файла шрифта.
