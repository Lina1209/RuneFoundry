# RuneFoundry — Creative Lab

Творческая лаборатория для рисования собственных рун и знаков. В редакторе можно рисовать мышью или пальцем, выбирать толщину линии, отменять последний штрих и очищать текущий знак.

## Возможности
- отдельные ячейки латиницы, кириллицы (включая Ё, Й, Ъ, Ь) и цифр;
- автосохранение проекта в браузере и восстановление после повторного открытия;
- сохранение отдельного рисунка в PNG и SVG прямо из редактора;
- экспорт проекта в JSON и импорт с проверкой структуры;
- ZIP-комплект проекта с JSON и SVG всех нарисованных знаков;
- адаптация интерфейса для смартфонов и установка как PWA.

## Важно
PNG — растровое изображение, SVG — векторный рисунок. ZIP — архив проекта и изображений, а не устанавливаемый шрифт. Экспорт TTF/OTF/WOFF/WOFF2 пока не реализован.

## Публикация
Приложение размещается через GitHub Pages из ветки `main`.
